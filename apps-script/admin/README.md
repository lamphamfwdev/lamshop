# LAM SHOP Admin

Web App quản trị sản phẩm, tối đa 5 ảnh, tồn kho, trạng thái, nội dung shop, ảnh hero, kênh bán hàng và bộ lọc giá. Đọc hướng dẫn đầy đủ tại `SETUP_ADMIN.md` ở thư mục gốc.

Các Script Properties bắt buộc:

- `SPREADSHEET_ID`
- `ADMIN_EMAIL`
- `CLOUDINARY_CLOUD_NAME`
- `CLOUDINARY_API_KEY`
- `CLOUDINARY_API_SECRET`

Không public API secret hoặc triển khai Admin cho người không được phép.
